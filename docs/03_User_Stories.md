# 03. User Stories

| ID | Persona | Story / Requirement | Functional Goal |
|---|---|---|---|
| US-01 | Engineer | As a Civil Engineer, I want to filter rate analysis items by Sector (Building vs Road) and search by code or description. | So I can locate relevant item codes (e.g. 7.2 or 1.01A) without knowing the exact syntax. |
| US-02 | Estimator | As an Estimator, I want to select a specific Fiscal Year and Zone (e.g., Metro A FY 2025/26) for my project. | So that all material, labor, and equipment rates automatically adopt the approved Zone Rates. |
| US-03 | Contractor | As a Contractor, I want to adjust Lead (transport distance in km) and Lift (vertical height) per item. | So the total delivered material cost correctly factors in haulage rates and handling expenses. |
| US-04 | Auditor | As a Project Auditor, I want to view a Material Statement showing total bulk quantities of Cement (bags), Rebar (MT), Sand (m³), and Labor days. | So I can cross-check project procurement requirements and logistics. |
| US-05 | Field Staff | As a Field Engineer in remote sites with no internet, I want to record BOQ quantities and compute rate analyses offline. | So I can complete estimates on my laptop and synchronize changes once back online. |
| US-06 | Data Admin | As an Admin, I want an automatic Data Cleaning tool that detects duplicate resources like '10mm Aggregate' and ''. | So the database remains clean without duplicate master entries. |
