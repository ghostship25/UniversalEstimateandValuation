# 17. Admin Manual

## Managing Master Resources & Zone Rates
1. Open **Master Data** -> **Resource Master**.
2. To update annual Zone Rates, navigate to **Zone Rates** and upload the official Zone Rate Committee Excel schedule.
3. System verifies resource code mappings and flags unmapped or missing items.

## Running Data Normalization & Cleaning
1. Open **Data Cleaning** tool.
2. Click **Scan Duplicates**.
3. Review suggested duplicate pairs (e.g. 'Aggregate 10mm' vs '10 mm Aggregate' vs '').
4. Select the primary canonical resource and click **Merge Resources**. All references in existing norms and BOQs will automatically update to the primary resource ID.
