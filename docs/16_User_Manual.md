# 16. User Manual

## How to Calculate a Rate Analysis Item
1. Go to the **Rate Analysis** tab from the top navigation bar.
2. Select your Target **Zone** (e.g., Metro A, Hills A, Plains C) and **Fiscal Year** (e.g. 2025/26).
3. Search for a Norm by entering code (e.g. `7.2` or `13.01A`) or text description in any language.
4. View the item breakdown: L (Labor), M (Material), E (Equipment) quantities and unit rates.
5. Optionally add custom **Lead (km)**, **Lift (meters)**, or **Royalty Tax**.
6. Export the official Rate Analysis breakdown sheet to **PDF** or **Excel**.

## How to Prepare a Project Estimate (BOQ)
1. Navigate to the **Projects & BOQ** tab.
2. Click **Create Project** and specify Project Title, Location, and Department.
3. Add items from the Norms library and specify estimated quantities.
4. Review the auto-generated **Abstract of Cost**, **Material Statement** (Cement, Steel, Sand, Aggregates), and **Labor Schedule**.

## How to Prepare a Valuation Measurement Book (Valuation MB)
1. Navigate to the **Valuation MB** tab.
2. Select or create an active MB session (e.g., `IPC 01`, `First & Final MB`).
3. Enter executed dimension sub-rows under BOQ items.
4. To add itemized provisional sums, click **`+ P.S. Item`** at the top or bottom action toolbar and enter item code, description, quantity, and unit rate.
5. Switch to the **Valuation Abstract** view mode to review the financial breakdown:
 - **Sub Total Executed Work**
 - **Grand Estimate Base**
 - **Approved Authority Budget**
 - **Authority Grant Share**
 - **Contingency Deduction ( %)**
 - **Public Participation Share**
 - **Previous Paid Installments**
 - **Net Authority Amount Payable**
6. Click **Print Abstract** or **Export Excel** to generate client-ready PDF/Excel valuation reports with auto-sized column widths and clean text wrapping.
