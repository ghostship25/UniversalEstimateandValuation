# 10. UI/UX Guidelines

## Visual Design System
- **Theme**: Professional Slate & Construction Amber Accent (#2563eb Primary Slate Blue, #f59e0b Amber Accent, #0f172a Deep Slate Text).
- **Typography**: Inter for English technical terms & numbers; any Unicode-capable font for descriptions in other languages.
- **Micro-Interactions**:
  - `CMD+K` Command Palette for rapid resource/norm navigation.
  - Smooth animated tab transitions using `motion/react`.
  - Color-coded badges for resource categories (Material: Emerald, Labor: Indigo, Equipment: Amber, Transport: Cyan).

## Specialized Layouts
1. **Interactive Rate Worksheet View**: A spreadsheet-style breakdown table displaying Quantity per Base Unit, Unit Rates, Subtotal, 15% Overhead, and Total Unit Cost.
2. **Material Statement Dashboard**: Donut charts showing cost allocation percentages across Material, Labor, and Equipment.
3. **Data Normalization Hub**: Split-screen diff viewer for merging duplicate resource items.
